## Core product idea

A premium personal gaming hub that combines:
- game discovery
- personal library tracking
- detailed game pages
- trailers and media galleries
- granular user ratings
- achievements/trophies metadata
- favorite games
- gaming profile and XP
- platform browsing including PS2 and PS3

The visual direction should feel cinematic and console-like, inspired by premium TV/console interfaces, but it must have its own identity and must not directly copy Apple TV or PlayStation UI.
